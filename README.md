# Student Results Management System

A simple Python-based student results management system built to bring together concepts covered in my Python Fundamentals series.

## Features

- Add student records
- Store student marks in a CSV file
- View student records
- Calculate student averages and grades
- Generate a class performance report

## Project Structure

- `main.ipynb` - Runs the application and handles user interaction
- `logic.py` - Calculates averages and grades
- `file_handler.py` - Saves and loads student records
- `report.py` - Generates the performance report

## Requirements

- Python 

## How to Run

Run `main.py` in your preferred Python environment.
